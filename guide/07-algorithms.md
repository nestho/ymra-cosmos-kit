# الگوریتم — ذهن چالش‌دوست اینجاست

تو گفتی تا مسئله حل نشود رها نمی‌کنی. المپیاد کامپیوتر دقیقاً همین عضله است.

## هدف تا بهمن

قبول شدن **مرحلهٔ اول** کامپیوتر. این مرحله بیشتر تفکر است تا کدنویسی حرفه‌ای. با این حال از حالا درست تمرین کن.

هدف غیرواقعی: طلای IOI امسال. نه.

## مسیر

```
فکر الگوریتمی → پایتون برای تمرین سریع → C++ برای مرحلهٔ دوم/تابستان
```

پایتون را بلدی. برای Bronze می‌شود با پایتون هم مسئله زد. برای المپیاد ایران در سطح بالاتر معمولاً **C++** لازم است. از دی، اگر مرحلهٔ اول خوب پیش رفت، هفته‌ای یک جلسه C++ شروع کن.

## تمرین

- [Codeforces](https://codeforces.com/) — مسئله با فیلتر `difficulty: 800-1200` و تگ `implementation`, `brute force`, `math`
- [CSES Problem Set](https://cses.fi/problemset/) — بخش Introductory
- [USACO](https://usaco.org/) — مسابقه رایگان جهانی؛ شهروندی آمریکا لازم نیست
- سؤال‌های مرحلهٔ اول المپیاد کامپیوتر ایران: جستجو در گاما / سایت‌های المپیاد کامپیوتر

روش هر مسئله:
1. ۲۰ دقیقه خودت
2. اگر نوک ایده آمد، ادامه بده تا ۴۰
3. اگر هیچی نبود، یک راهنمایی (نه کد کامل)
4. بعد از دیدن حل، **از صفر خودت پیاده کن**
5. فردا همان را بدون نگاه کردن دوباره بنویس اگر سخت بود

## هفته‌ای ۳ مسئله یعنی چه؟

کمیت کم، کیفیت بالا. ۳ مسئلهٔ فهمیده > ۲۰ مسئلهٔ کپی.

دفتر الگوریتم جدا: مسئله، ایده، پیچیدگی خیلی مقدماتی (چرا n² ممکن است کند باشد).

## اتصال به نجوم

الگوریتم در TESS یعنی:
- جستجوی دوره (periodogram) = جستجو روی فضای پارامتر
- fold = مرتب‌سازی فاز
- تشخیص ترانزیت = الگوی تکراری در آرایه

وقتی BLS را در اسکریپت ۲ می‌بینی، همان «جستجوی کامل هوشمند» است.
