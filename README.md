# کیت کیهان — یمره

نقشهٔ یادگیری **نجوم، فیزیک، ریاضی، الگوریتم** و یک پروژهٔ واقعی با دادهٔ **ناسا**.

این ریپو برای کلاس دهم، سال تحصیلی ۱۴۰۵–۱۴۰۶ ساخته شده. هدف‌اش مدرک جمع کردن نیست. هدف‌اش این است که کار واقعی بکنی، بفهمی، و پرونده‌ای بسازی که بعداً المپیاد، دانشگاه و آزمایشگاه را باز کند.

---

## یمره، اول این را بخوان

تو دورهٔ پایتون را جزو ۱۰۰۰ نفر برتر تمام کردی، بعد کورس ۴۰ ساعتهٔ **Stanford Data Ocean** (AI/ML و بیوانفورماتیک، دپارتمان Genetics استنفورد) را **بدون هوش مصنوعی** و با نمرهٔ نزدیک حد نصاب پاس کردی. سخت‌ترین چالش را رها نکردی تا حل شد.

این از ده مدرک ۲۰ از ۲۰ با ChatGPT باارزش‌تر است.

حالا قدم بعدی **کورس بعدی استنفورد نیست**. قدم بعدی عمق است:

1. المپیاد **نجوم** (اصلی) + **کامپیوتر** (الگوریتم)
2. یک پروژهٔ واقعی با دادهٔ تلسکوپ **TESS ناسا**
3. ریاضی زیرساختی که هم المپیاد و هم ML را می‌فهماند

## قانون‌های این کیت

1. **بدون فهمیدن رد نشو.** اگر گیر کردی، همان‌جا بمان. این نقطهٔ قوت توست.
2. **هوش مصنوعی جای فکر کردن نیست.** اگر گیر کردی اول خودت ۲۰–۳۰ دقیقه کلنجار برو، بعد از انسان (معلم / این ریپو / منبع) بپرس. کد آماده کپی نکن مگر داری API را یاد می‌گیری.
3. **کورس جدید نگیر** تا پروژهٔ TESS و مرحلهٔ اول المپیاد تمام شود.
4. **فیزیک امسال نمایشی است.** آزمون بدهی خوب است، ولی مدال فیزیک از سال یازدهم است. امسال انرژی را روی **نجوم** و **کامپیوتر** بگذار.

---

## سه ستون امسال

```
نجوم (المپیاد)     الگوریتم (کامپیوتر)     پروژهٔ TESS (دادهٔ ناسا)
        \                |                    /
         \               |                   /
          +------ اخترفیزیک محاسباتی ------+
```

این ترکیب همان کاری است که رصدخانه‌ها و ناسا واقعاً انجام می‌دهند: فیزیک + ریاضی + کد + داده.

## تقویم سریع ۱۴۰۵–۱۴۰۶

| زمان | چه می‌شود |
|---|---|
| شهریور–مهر | راه‌اندازی پایتون نجومی + شروع مکانیک و نجوم کروی |
| آبان | عمق المپیاد + اولین سیاره در TESS |
| **آذر** | **ثبت‌نام المپیاد** در [my.medu.ir](https://my.medu.ir) |
| ۱۴–۱۵ نوامبر ۲۰۲۶ | [NASA Space Apps](https://www.spaceappschallenge.org/) (اختیاری اگر تیم پیدا شد) |
| دی | جمع‌بندی مرحلهٔ اول + مسئله‌های سال‌های قبل |
| **بهمن** | **آزمون مرحلهٔ اول** (نجوم + کامپیوتر) |
| اسفند–بهار | اگر قبول شدی: مرحلهٔ دوم |
| تابستان ۱۴۰۶ | اگر راه یافتی: دورهٔ باشگاه دانش‌پژوهان جوان |

تاریخ دقیق آزمون را از اطلاعیهٔ [باشگاه دانش‌پژوهان جوان](https://ysc.medu.ir) چک کن. سال قبل مرحلهٔ اول حدود ۱۲–۱۹ بهمن بود.
