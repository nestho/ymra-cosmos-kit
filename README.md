## یمره، اول این را بخوان

دورهٔ پایتون را جزو ۱۰۰۰ نفر برتر تمام کردی، بعد کورس ۴۰ ساعتهٔ Stanford Data Ocean را **بدون هوش مصنوعی** و با نمرهٔ نزدیک حد نصاب پاس کردی. سخت‌ترین چالش را رها نکردی.

قدم بعدی کورس استنفورد دوم نیست:

1. المپیاد **نجوم** (اصلی) + **کامپیوتر**
2. پروژهٔ **TESS** با دادهٔ ناسا
3. ریاضی زیرساخت

## قانون‌ها

1. بدون فهمیدن رد نشو.
2. هوش مصنوعی جای فکر کردن نیست.
3. کورس جدید نگیر تا TESS و مرحلهٔ اول تمام شود.
4. فیزیک امسال نمایشی است.
